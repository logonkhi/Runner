Mobile Camera Pose Runner

핸드폰 브라우저용 카메라 동작 인식 러닝 게임
CAM 대기 POSE 대기 CAL 필요
입력: NONE
달리기: 0%
카메라 인식이 흔들릴 때 터치로 백업 조작합니다.

핸드폰 테스트 방법

1. GitHub Pages, Netlify, Vercel, ngrok 같은 HTTPS 주소에서 실행하세요. 모바일 브라우저는 일반 HTTP에서 카메라 권한을 막는 경우가 많습니다.

2. 핸드폰은 가로 방향을 추천합니다. 전신이 들어오도록 1.5~2.5m 정도 떨어져 서세요.

3. 카메라 버튼을 누르고 권한을 허용한 뒤, 정면으로 서서 보정 버튼을 누르세요.

4. 제자리 달리기는 게임 속도를 올리고, 좌우 이동/점프/앉기/펀치/양팔 들기 포즈가 게임 입력으로 들어갑니다.

5. 모바일에서는 인식이 불안정할 수 있어서 하단 터치 버튼을 백업 입력으로 넣었습니다.
