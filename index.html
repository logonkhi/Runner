핸드폰 테스트 방법

1. HTTPS 주소에서 실행하세요. GitHub Pages, Netlify, Vercel, ngrok 모두 가능합니다.

2. 카메라 버튼을 누르고 권한을 허용합니다.

3. 전신이 들어오게 1.5~2.5m 정도 떨어져 선 뒤 보정 버튼을 누릅니다.

4. 제자리 달리기, 좌우 이동, 점프, 앉기, 펀치, 양팔 들기 포즈를 테스트합니다.

5. 이번 버전은 Phaser를 제거하고 Canvas 2D로 직접 그리기 때문에 모바일에서 게임 화면이 더 안정적으로 표시됩니다.
